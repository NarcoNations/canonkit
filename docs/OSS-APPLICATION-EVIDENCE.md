# Open-source application evidence

This is a truthful evidence register for a future Vercel OSS Programme application. It is not an application and must not convert plans into delivered claims.

## Existing evidence

| Criterion | Current evidence | Status |
| --- | --- | --- |
| Open-source repository | Public MIT-licensed CanonKit repository | Exists |
| Active development | Ordered merged checkpoints, CI history, roadmap, changelog, and handover | Exists |
| Maintained project | Security, contribution, support, maintenance, and release policies | Exists after this checkpoint |
| Hosted or intended for Vercel | Public concept site deployed from the repository | Exists |
| Community standards | Code of Conduct and bounded contribution workflow | Exists |
| Functional tool | Local CLI and library pass package, process, and cross-platform rehearsals | Exists |
| Public installation | npm package | Blocked by RB-001 and RB-005 |
| External usage | Verified users, dependent repositories, downloads, or feedback | Not yet evidenced |
| Measurable impact or growth potential | Honest adoption indicators and use cases | Partly explainable; no measured adoption yet |

## Evidence to capture after publication

- public npm package and provenance link
- install instructions tested from the registry
- public release and immutable source tag
- issue, discussion, or feedback links from real users
- npm download counts with the observation date and source
- repository stars, forks, contributors, and dependent projects with observation dates
- examples of public repositories using CanonKit, with permission where attribution is needed
- maintenance actions and releases demonstrating continued activity
- production site and public documentation links

## Evidence rules

- Record dated source links, not unsupported summaries.
- Distinguish repository activity from external adoption.
- Do not count synthetic fixtures, maintainer testing, or automated checks as community usage.
- Do not claim customer, VibeLabz, NarcoNations, MAG, or private-repository usage in the public application.
- Mark planned integrations and future capabilities as proposed.
- Re-check the programme's live eligibility criteria and application status immediately before submission.

## Application checkpoint

Do not submit until CanonKit is publicly installable, the application window is open, the maintained-project evidence is current, and there is at least one honest signal of external use or feedback. Final submission remains an explicit maintainer action.
